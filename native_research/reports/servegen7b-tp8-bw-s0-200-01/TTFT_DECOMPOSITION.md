# TTFT 等待拆分：ServeGen 200 筆、seed 0、TP8

各欄均為每請求平均值，單位為秒。
本次十組使用完全相同的 200 筆輸入。

```text
TTFT = 前輪等待 + 准入預算等待 + 通過准入至首 token
前輪等待 = max(0, parent.completed_at - original_arrival)
准入預算等待 = native_budget_wait_s
```

通過准入至首 token 仍包含原生排程、計算與傳輸，不能全數當成純 prefill。
